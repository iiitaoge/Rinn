# Project Rinn 毕业设计指导过程记录对应段落

生成依据：原《本科毕业设计（论文）指导过程记录表》的过程环节与主题；项目内容来自 docs/thesis 中的 Project Rinn 论文材料。

可直接使用的完整版本已写入 Word 表格：Project_Rinn_本科毕业设计指导过程记录表_个性化.docx。

## 写法迁移规则

每一段都按“指导动作 + 项目内容 + 修改要求/成果要求”组织。例如：

- 指导动作：指导梳理、审阅修改、要求补充、检查进度。
- 项目内容：ECS、SparseSet、Lua+sol2、raylib、HD-2D、NPC AI、测试。
- 成果要求：对应论文结构、代码实现、测试数据、图表截图、格式规范。

这样写出来的记录才不像通用模板，而像围绕 Project Rinn 的真实指导过程。
