  你问的盲区,我看到三层,从浅到深:

  1. 表层:从特例直接跳到一般结论

  你的推理链是:

  ▎ 东南西北只能管 xz → 所以任何角度都不行

  中间漏了一步:"东南西北是哪一类角度的特例?"它是"水平方向的 1

  ▎ 抽象动作:碰到 X 失败,先问"X 是什么的特例?它的兄弟姐妹是谁?"——不要直接给 X
  所属的整个类别判死刑。

  2. 中层:没有数自由度 (DOF) 的习惯

  这是个更通用的工具。任何"用什么 UI 表达 X"的问题,先回答两个数:
  - 数据 X 有几个自由度?
  - UI 暴露了几个?

  回这道题:

  ┌────────────────────┬─────────────────────────────────────┐
  │         量         │                 DOF                 │
  ├────────────────────┼─────────────────────────────────────┤
  │ 单位方向向量 |v|=1 │ 3 分量 − 1 长度约束 = 2             │
  ├────────────────────┼─────────────────────────────────────┤
  │ SliderFloat3       │ 3,多 1 → 你抓到的"重复"就是这个冗余 │
  ├────────────────────┼─────────────────────────────────────┤
  │ 东南西北           │ 1,少 1 → 缺一维                     │
  └────────────────────┴─────────────────────────────────────┘

  数清楚,widget 几乎自己跳出来。这个习惯能迁移到 UV
  映射、相机控制、四元数旋转——所有"参数化"问题同一套套路。

  3. 深层:你脑子里方向 = 3 个数,这是代数模型。缺的是几何模型——方向住在球面 S² 
  上。

  球面是嵌在 3D 里的一个 2D 曲面。所以方向本质就是 2 维的,这就是为什么 2
  个角刚好够用——球面坐标就是 S² 这个 2D 曲面的天然坐标。

  如果你脑子里"方向 = 球面上的一个点",那"几个数定位它"的答案是秒答的。

  ---
  三层是嵌套的: 几何模型有 → DOF 自然会数 → 不会被特例困住。

  练习建议:以后碰到"用 N 个数描述 X"的设计问题,先 30 秒回答 → "X
  在数学上是什么?有几个 DOF?约束是什么?" 再动手选 widget。
