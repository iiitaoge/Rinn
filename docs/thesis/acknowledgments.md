# 致谢

时光飞逝，毕业设计的撰写也接近尾声。回望这段时间从零搭建 Project Rinn 引擎、反复推敲 ECS 设计、调试 shader、撰写论文的全过程，我深感这是一段难得的、沉浸式的成长经历。在此，谨向所有给予我帮助与支持的师长、同学和家人致以最诚挚的谢意。

首先，衷心感谢我的指导老师 ◯◯◯ 老师。从课题选题阶段对方向的把关、到研究过程中对架构与代码细节的耐心指点、再到论文写作阶段对结构与表达的反复打磨，老师都给予了极大的帮助。老师严谨求实的治学态度、对工程问题的深刻洞察以及对学生独立思考能力的尊重，都将成为我未来学习与工作中长久的榜样。

感谢计算机科学与工程学院的各位授课老师。正是在他们循序渐进的教学中，我才打下了 C++ 编程、数据结构、操作系统、计算机图形学等课程的基础，从而在面对自研游戏引擎这样综合性强、技术跨度大的课题时不至于无从下手。

感谢同实验室、同班级的同窗们。在与诸位的讨论中，许多原本困惑已久的问题豁然开朗；在彼此的代码评审中，我才意识到自己思维的盲区与设计的缺陷。这段并肩前行的时光，是大学四年最宝贵的回忆之一。

感谢开源社区。raylib、Lua、sol2、Dear ImGui、GoogleTest、EnTT 等优秀项目为本课题的实现奠定了基础，其作者与维护者用代码诠释了"分享"二字的真正力量。Mike Acton、Skypjack、Jason Gregory 等业界前辈通过演讲、博客、书籍向后来者传递的工程智慧，更是本课题在面对复杂设计抉择时反复参考的灯塔。

最后，感谢父母多年来一如既往的支持与理解。在选择这条并不轻松的道路时、在面对困难与挫折时，是你们给予我最坚实的依靠。

学海无涯，前路漫漫。Project Rinn 的工作只是一个起点。在毕业设计之外，我将继续完善这一引擎，让它真正承载起一款完整的 HD-2D 作品。

谨以本文向所有帮助过我的人，致以最诚挚的谢意。
