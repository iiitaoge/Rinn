## 🎮 Demo 概念

### 一句话描述

> **一个像素风小村庄，NPC 会自主生活、感知环境、记住你做过的事、根据需求做决策——你的每一个行为都可能在村庄中引发涟漪。**

### 核心体验

玩家扮演一个访客进入村庄，可以：
- 自由探索像素风 HD-2D 场景
- 与 NPC 互动（给予物品、帮助或攻击）
- 观察 NPC 之间自发形成的社会关系
- 发现自己的行为如何在 NPC 群体中传播和产生连锁反应

## 👥 NPC 行为

### 日常生活循环

**每个 NPC 都有基本需求驱动行为**：

```
        饥饿 ↑             疲劳 ↑
            │                 │
            ▼                 ▼
       去面包房吃饭      回家睡觉
            │                 │
            └──── 需求满足 ────┘
                     │
                     ▼
                继续日常活动
         (工作/闲逛/社交/采集)
```

### 典型 NPC 一天

| 时间 | 行为 |
|------|------|
| 🌅 早晨 | 离开家，前往工作地点 |
| ☀️ 白天 | 在工作地点劳动 (铁匠铺/农田/商店) |
| 🌙 傍晚 | 前往酒馆闲聊、吃饭 |
| 🌑 夜晚 | 回家休息 |

## 🧠 涌现行为示例

### 场景 1: 社会关系形成

```
玩家给农夫 Fritz 一个苹果
        ↓
Fritz 正在饥饿状态 (Needs.hunger = 200/255)
        ↓
Lua 评估: 苹果价值 = 高 (因为他快饿死了)
        ↓
Fritz 对玩家的好感度 +50
        ↓
Fritz 会在未来帮助玩家 (分享信息/提供帮助)
```

**如果玩家给一个刚吃完饭的 NPC 苹果**：
```
NPC 不饿 (Needs.hunger = 20/255)
        ↓
苹果价值 = 低
        ↓
好感度只 +5
```

### 场景 2: 信息传播

```
玩家在农田偷了东西，被农夫 Fritz 看到
        ↓
Fritz 的 Memory 写入: { Event: SAW_THEFT, who: 玩家 }
        ↓
傍晚 Fritz 去酒馆
        ↓
Fritz 对 NPC 们说话 (传播信号)
        ↓
酒馆里的 NPC 都写入: { Event: HEARD_RUMOR, content: "新来的人是小偷", certainty: 低 }
        ↓
第二天，没去酒馆的商人 Klaus 还不知道这件事
        ↓
但 Klaus 的朋友告诉了他...
```

### 场景 3: 涌现式复仇

```
玩家杀死了铁匠 Hans
        ↓
是否有目击者？
    │
    ├── 有目击者 → 目击者记住凶手 → 报告给其他人 → 村民敌视玩家
    │
    └── 无目击者 → 无人知道凶手 → 玩家可以若无其事地继续生活
                   │
                   └── 但如果有人看到尸体 → 开始调查 → 可能找到线索
```

### 场景 4: 派系冲突

```
铁匠 Hans 和面包师 Otto 因为债务产生矛盾
        ↓
Hans.opinions[Otto] = -60 (敌对)
Otto.opinions[Hans] = -40 (讨厌)
        ↓
如果玩家帮助 Otto → Hans 对玩家好感下降
如果玩家帮助 Hans → Otto 对玩家好感下降
        ↓
村庄可能自发形成两个派系
```

## ⚙️ 核心系统

### 意识流水线

```
信号 (瞬时)  →  Sensors (过滤)  →  Memory (存储)  →  Needs (评估)  →  Action (执行)
    │               │                │                  │              │
  枪声           视野内？         记住位置           有危险？       逃跑
  脚步声         距离够近？       记住是谁           饿了？         去吃饭
  给予物品       能看到？         记住对方好感       累了？         回家休息
```

### 涌现关键

1. **主观认知**: 每个 NPC 只知道自己看到/听到的事
2. **信息衰减**: 谣言传播时 certainty 降低
3. **需求驱动**: 行为由 Needs 状态决定，不是脚本
4. **关系动态**: 好感度随交互实时变化
5. **无全知**: 杀掉目击者 = 信息无法传播 = 可能的完美犯罪

## 🎯 演示场景脚本

### 开场 (自动播放)

1. 淡入场景，村庄广场，清晨
2. NPC 陆续从家中出来，前往各自工作地点
3. 几秒后玩家出现在村口

### 玩家自由探索

- 玩家可以四处走动
- 可以观察 NPC 的日常行为
- 可以与 NPC 交互

### 建议演示路线

1. **给面包师 Otto 一个苹果** → 观察好感变化
2. **等待傍晚，去酒馆** → 观察 NPC 聚集社交
3. **在无人处偷取物品** → 观察是否被发现
4. **攻击一个 NPC** → 观察其他 NPC 反应
